# AURA Messenger — стартовый проект

AURA — адаптивный веб-мессенджер с интерфейсом в духе Telegram и собственным визуальным стилем.

## Что уже заложено

- React + TypeScript + Vite.
- Подключение Supabase Auth.
- Профиль пользователя: имя, username, bio, уникальный AURA ID.
- Каталог цифровых подарков и RPC для безопасного получения бесплатного подарка.
- Базовые таблицы чатов, участников и сообщений.
- Realtime-подписка на новые сообщения.
- Разделы контактов, подарков, профиля, Premium, маркетплейса и настроек.
- Адаптивная компоновка для мобильных устройств.

## Запуск локально

Требуется Node.js 20+.

```bash
npm install
cp .env.example .env
```

Создай проект в Supabase, затем заполни `.env`:

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY
```

В Supabase открой **SQL Editor**, вставь и выполни содержимое:

`supabase/migrations/0001_aura_schema.sql`

Затем запусти:

```bash
npm run dev
```

Для production-сборки:

```bash
npm run build
```

## Важные замечания перед публичным запуском

1. В браузере используется только publishable/anon key. Никогда не добавляй `service_role` key во frontend.
2. Проверь RLS-политики и настройки подтверждения email в Supabase.
3. Чаты сейчас имеют базовый каркас. Нужны серверные функции для безопасного создания личных диалогов, добавления участников, блокировок и жалоб.
4. Поиск контактов, загрузка аватаров/обложек, отправка медиа, push-уведомления и полноценные настройки приватности — следующие этапы.
5. AURA ID — внутренний публичный идентификатор, не номер телефона. Номер телефона не публикуется в профиле.
6. Подарки сейчас являются внутриигровыми цифровыми предметами в базе данных, а не NFT в блокчейне. Реальные токенизированные активы требуют отдельного проектирования, кошельков, юридической и возрастной проверки.
7. Premium сейчас информационный раздел без платежей. Подключать оплату можно только после проектирования серверной проверки подписки и возвратов.

## Структура

- `src/App.tsx` — интерфейс и базовые действия.
- `src/styles.css` — оформление и адаптивность.
- `src/lib/supabase.ts` — Supabase client.
- `supabase/migrations/0001_aura_schema.sql` — схема, триггеры, RPC и RLS.
